# Glossary

| Term | Means | Not |
| --- | --- | --- |
| Meeting | One saved call with its transcript, notes, and summary | session, recording |
| Segment | One finished or partial transcript line from one channel | utterance, chunk |
| Them | The other side of the call, from system audio | interviewer, remote |
| Me | Nils's own voice, from the microphone | user audio |
| Mode | A named prompt and notes style for a kind of call | persona, preset |
| Context file | A local file (resume, job description, notes) that grounds answers | knowledge base, document |
| Pinned | A context file that is always sent with a question | starred, favourite |
| Answer | The model's suggested reply, streamed into the overlay | response, completion |
| Overlay | The floating panel that sits above the call window | HUD, widget |
| Provider | The model source: local Ollama or an OpenAI-compatible endpoint | vendor, plan |
